# Roadmap

The roadmap is deliberately narrow. Items move into implementation only after real use supports them.

## Milestone A — Documented personal MVP

- [x] Core capture and annotation flow.
- [x] Clipboard-first export.
- [x] Pop!_OS launcher.
- [x] Tray and login autostart.
- [x] Global GNOME shortcut.
- [x] Project handoff documentation.
- [ ] Replace temporary interface and brand assets.
- [ ] Confirm copyright and brand policy.

## Milestone B — Public GitHub alpha

- [ ] Create public repository.
- [ ] Add repository description, topics, screenshots, and demo GIF/video.
- [ ] Configure CI.
- [ ] Publish `v0.2.1-alpha.1` or a newer tested tag.
- [ ] Provide source install instructions and known limitations.
- [ ] Recruit a small group of X11 testers.
- [ ] Triage first external issues.

## Milestone C — Reproducible Linux package

- [ ] Choose a stable reverse-DNS application ID.
- [ ] Add AppStream metadata.
- [ ] Build and test a Flatpak manifest.
- [ ] Verify X11 capture and tray behavior in the sandbox.
- [ ] Test install, update, and removal from a clean system.
- [ ] Submit to Flathub after stability requirements are met.

## Later evaluation

- [ ] Wayland capture backend.
- [ ] Broader desktop compatibility.
- [ ] Mixed-DPI and multi-monitor robustness.

## Not planned without a product-direction decision

- OCR.
- Cloud sharing.
- Screenshot history.
- Accounts.
- Plugin platform.
- General image-editing tools.
